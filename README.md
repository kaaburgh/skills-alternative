# Skills Alternative

An evidence-first experiment for deciding whether a useful “AlternativeTo for agent skills” can exist on top of current skill catalogs.

The first deliverable is deliberately **not a website**. It is a frozen, reproducible data prototype: a cohort of popular public skills, provenance-aware evidence cards, alternative candidates, a held-out manual audit, and a pre-committed Keep/Pivot/Kill decision.

See [`ROADMAP.md`](./ROADMAP.md) for the authoritative experiment plan and [`docs/roadmap-review.md`](./docs/roadmap-review.md) for the independent review that shaped it, plus [`docs/roadmap-review-second-pass.md`](./docs/roadmap-review-second-pass.md) for the second-pass audit of the revised plan.
